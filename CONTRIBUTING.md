## Features

- Write daily entries with rich text, inline photos, audio notes and custom tags
- Navigate all past entries through a calendar view, timeline and full-text search
- Attach mood, weather and location data to every entry for later review
- Protect the journal with a password lock and create encrypted local backups
- Export entries to PDF, HTML, DOCX or plain text for archiving and printing
